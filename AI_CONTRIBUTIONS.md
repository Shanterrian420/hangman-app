# AI Contributions

## AI Tool Used
ChatGPT (OpenAI)

## Purpose of AI Assistance
ChatGPT was used as a development assistant throughout the creation of this Hangman application.

## Areas Where AI Assisted

### 1. Frontend Development
- Helped develop and organize React components.
- Assisted with implementing the Hangman game logic.
- Helped troubleshoot image display and styling issues.
- Assisted with displaying player statistics and winning percentages.

### 2. Backend Development
- Assisted with setting up the Express.js server.
- Helped create the GET, POST, and PUT API endpoints.
- Helped troubleshoot API requests and responses.

### 3. Database Integration
- Assisted with configuring DynamoDB Local.
- Helped connect the backend to DynamoDB using the AWS SDK.
- Helped implement player registration and persistent win/loss tracking.

### 4. Testing and Debugging
- Helped troubleshoot errors in the frontend and backend.
- Assisted with testing API endpoints using terminal commands.
- Helped verify that player statistics updated correctly after games.

### 5. Documentation
- Assisted with writing and organizing the project README.
- Helped document project setup instructions and API endpoints.

## Student Contributions
The student worked directly in Visual Studio Code to implement, modify, run, and test the application. ChatGPT provided explanations, suggestions, and debugging assistance throughout development.

## Summary
AI assistance was used as a learning and development resource. The student remained involved in building, testing, and understanding the application.
